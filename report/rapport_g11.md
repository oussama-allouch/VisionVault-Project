# Rapport académique VisionVault G11

La version finale du rapport est distribuée avec les livrables sous les noms `Rapport_VisionVault_G11.pdf` et `Rapport_VisionVault_G11.docx`. Elle regroupe les sources scientifiques vérifiées, les données mesurées, les captures de l’application et les résultats des tests. Le projet utilise GHIM-10K et Re-weighting Type-1.
