# Validation du mini-projet G11

La matrice d’exigences, le journal des tests, les expériences et l’archive reconstruite sont fournis dans le dossier de livrables. Les pièces sont ventilées dans `05_Resultats_Experimentaux`, `06_Captures_Reelles` et `07_Validation`.

Les contrôles reproductibles figurent dans le [README](README.md). Les tests vérifient le calcul des cinq familles, la formule Type-1, le flux Flask, les écritures SQLite, le rechargement de l’index, le catalogue GHIM-10K et le parcours Playwright avec l’environnement de test configuré.
